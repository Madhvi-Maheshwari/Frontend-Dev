Responsive CSS Cheat Sheet

🎨 Filters

Use CSS filters to apply effects like blur(), grayscale(), or sepia() on images.
Example: filter: grayscale(100%);

📱 Media Queries

Define styles for different screen sizes.
Example: @media (max-width: 600px) { ... }

🧩 Responsive Design

Use flexible layouts like Flexbox or Grid, and relative units (%, vw, fr) for adaptable designs.

🔠 Typography

Make font sizes scale with clamp() for fluid, readable text.
Example: font-size: clamp(1rem, 2vw, 2rem);
